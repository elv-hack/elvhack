## 代码

代码块会按亮/暗主题自动切换配色，右上角有复制按钮。

```ts
// 一个最小的粒子：位置 + 年龄
interface Particle {
  x: number;
  y: number;
  age: number;
}

function step(p: Particle, angle: number, speed = 1.2): Particle {
  return { x: p.x + Math.cos(angle) * speed, y: p.y + Math.sin(angle) * speed, age: p.age + 1 };
}
```
